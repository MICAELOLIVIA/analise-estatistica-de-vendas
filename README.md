# Análise Estatística de Vendas com Python

## Sobre o projeto
Projeto acadêmico de análise estatística de vendas utilizando dados simulados, desenvolvido para investigar se as vendas médias nos finais de semana são superiores às dos dias úteis.

## Tecnologias utilizadas
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Google Colab

## Etapas do projeto
1. Preparação e exploração dos dados.
2. Análise estatística descritiva.
3. Visualização dos dados.
4. Aplicação do teste t de Welch para amostras independentes.
5. Interpretação dos resultados.

## Resultados
O teste estatístico não apresentou evidências suficientes, ao nível de significância de 5%, para concluir que as vendas médias nos finais de semana são superiores às dos dias úteis.

## Conclusão
O projeto demonstra a aplicação de Python, análise exploratória de dados e testes de hipóteses para investigar uma questão de negócio.

## Observação
Os dados utilizados são simulados e têm finalidade educacional.
